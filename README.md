## AI-Powered Incident Automation API

This project provides an automated incident response system built with Python and Flask. It listens for incoming incident alerts, uses a knowledge base to determine severity and suggest remedies. It then undertakes a bunch of alert processes like creating dedicated Slack channels, notifying stakeholders, and generating GitHub issues for tracking. It also adds the response in a sqlite db.
